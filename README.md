> 今生善用其心，來世同佛出家。

## 內容規劃（已定）

- 第一人稱寫簿；畫面有「來生的我」（背影、低眉垂目）
- 五個分頁：福田（首頁）、淨行、功課、讀誦、出家簿
- 首頁：一件正在縫成的袈裟，十六塊田相對應「十六關」（設計象徵，非經典規定）
- 功課四張卡：禪堂、平日用餐（是否收攝身心，依食存五觀）、十善業道、八關齋戒
- 十三則警語（九則水彩漫畫、四則文字說明）與十六關：依聖嚴法師《律制生活》〈求度出家的條件〉
- 讀誦與深入：六十華嚴與八十華嚴並排

## 資料與版本說明

- **主誦與主講**：六十華嚴（東晉佛馱跋陀羅譯，T09n0278 卷6〈淨行品第七〉）。依據：聖嚴法師在香港等地宣講的是晉譯〈淨行品〉，並說六十卷本也很好（法鼓全集 06-10《空花水月》；《聖嚴法師年譜》1997、1998 年）。
- **並排**：八十華嚴（唐實叉難陀譯，T10n0279 卷14〈淨行品第十一〉）。
- **選讀**：支謙《菩薩本業經》（同本異譯，經號待核）。
- 兩本用字有差異，例如出家一願：六十華嚴作「如佛出家，開導一切」，八十華嚴作「同佛出家，救護一切」（初核，建置時機器逐字比對）。
- 聖嚴法師說淨行品為一百四十一願（法鼓全集 07-10《菩薩行願》），仍以 CBETA 計數為準。
- 十三難、十六遮以聖嚴法師所列為主（法鼓全集 05-05《律制生活》），與其他來源不同處會在「深入」頁並列說明。
- 資料標記：已核對／初核／待核；查不到出處的內容不放入工具。
